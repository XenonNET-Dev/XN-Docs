联机为游戏内自带的 “店内对战” 模式。  
店内对战模式依靠的通信方式是本地局域网通信。  
因此，联机分为以下两种情况：  

- 远程联机（依靠远程虚拟局域网）  
- [本地联机](#本地联机)（依靠本地局域网）  

## 远程联机

远程联机需要先加入“CiRCLE联机中心”。  
CiRCLE联机中心不收取任何费用，所有服务器费用目前都是群管理直接承担。  

:::warning
当前CiRCLE联机中心使用的是SoftEther方案，该方案存在已知的：
- 揽车被揽车不减速,碰撞比较弹，物理上类似OCM.
- 后车一个角度顶前车屁股，前车可能会有不正常加速.
- 碰撞遇到弯道或下坡两车会一起起飞.

若对此介意请您慎重申请CiRCLE联机服务。
:::

### 加入联机中心

以下是申请加入的流程：  

::: steps
1. 确认信息

    确认您的QQ号对应的 `XenonNET Hub` 账户处于可用状态。  
    单个QQ只能拥有一个CiRCLE联机账户。  

2. 填写申请问卷

    前往并填写问卷：[CiRCLE 账户申请](https://docs.qq.com/form/page/DR3pPYUhZTFhrSFRL)  
    其中有使用联机服务时的基本守则需要知悉，以及确认您阅读过本联机。  

3. 联系管理员

    申请表填写完成后，请联系CiRCLE的管理员。  
    在提交申请后，请耐心等待，管理员将会按序审核提交的申请，如您符合要求将为您创建账户并提供登录联机软件以及联机管理平台的账户名和密码。
    若您审核未通过，将会告知原因。

    :::tip 寻找管理员方法
    在 `XenonNET群` 的 `群聊成员` 中搜索 `CiRCLE` 出现的群成员为CiRCLE联机中心管理员，请根据成员名寻找对应的管理员。
    :::

4. 申请加入联机群聊

    在得到账户名后，请添加CiRCLE联机群，加群时请备注我们提供给您的用户名。  
    
    ==> [添加群聊](https://qm.qq.com/q/VTBYVo2TCw)  
:::
