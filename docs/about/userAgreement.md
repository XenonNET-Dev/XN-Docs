欢迎加入 **Xenon NET**（以下简称“本服务器”）！  
请务必仔细阅读并同意以下内容。凡在群内活动或注册账号的用户，==均视为已同意本协议=={.important}。  
本服务器旨在提供娱乐与交流体验，==不具备任何商业运营性质=={.info}。  

## 一、服务器说明

1. 本服务器由服主及其合伙人、管理员们自发建立，供用户自由体验与交流。  
2. 本服务器与官方游戏及其开发商、发行商 ==无任何关联=={.important}。  
3. 所有数据、配置及内容 ==仅供学习与娱乐使用=={.note}。  

## 二、群聊基本规则

1. **文明发言**：==禁止=={.danger} 辱骂、阴阳怪气、地域攻击、人身攻击等行为。  
2. **禁止引战**：持不同意见请理性交流，==不得=={.danger} 引发争吵或群体对立。  
3. **拒绝广告**：==严禁=={.danger} 发布推广、外挂、其他服务器等相关广告。  
4. **禁止违规内容**：不得发布涉及 ==色情、政治、赌博、血腥或任何违法=={.danger} 信息。  
5. **尊重隐私**：==禁止公开=={.warning} 他人个人信息、聊天截图或任何私人资料。  
6. **友好交流**：==共同营造良好氛围=={.tip}，新用户提问请多包容，老用户应多帮助。  

## 三、数据与账号

1. 用户需注册以生成唯一用户信息，游戏内卡号与数据将与账号绑定，请 ==妥善保管账号及卡号=={.warning}。  
2. 每位用户仅限 ==拥有一个账号=={.important}，并须与其 QQ 号绑定。若用户离开群聊，账号将 ==被锁定=={.warning}，直至重新加入。  
3. 若同一用户使用不同 QQ 号注册多个账号并使用不同游戏数据，==除特殊情况外，所有账号将被封禁=={.danger}。  
4. 若因资金不足或其他 ==不可抗力=={.warning} 因素导致服务器关闭，服主与管理组 ==不承担任何责任=={.important}。  
5. 严禁对本服务器提供的任何资源进行 ==任何形式的涉及金钱的交易行为=={.danger}，尤其禁止以提供 “安装服务” 等为由对其他用户提供收费的安装服务。

1. 本服务器 ==不设任何形式的充值系统=={.important}。  
2. 服务器仅会在将要续费服务器时才会开放赞助通道。当筹集到的赞助款项足以进行续费时，赞助通道会再次关闭。具体赞助通道事宜将会在 XenonNET Hub 中进行发布。

4. 赞助款项仅用于服务器维护与运行支出，==赞助后不提供退款=={.warning}。  

## 五、违规处理

1. 违反本协议或群规的成员 ==将视情节轻重予以警告、移出群聊或封号处理=={.danger}。  
2. 管理组有权根据实际情况 ==直接处理=={.important}，不接受无理争辩。  
3. 被处理成员若使用小号再次加入群聊，==经发现后将直接封禁=={.danger}。  
4. 若用户认为处理存在不当，可在提供 ==充分证据=={.info} 的前提下提出申诉。申诉成功后，管理组将 ==撤销处罚并给予相应补偿=={.tip}。  
5. 管理组处理事务时 ==将秉持公正原则=={.important}，不偏袒任何一方。
