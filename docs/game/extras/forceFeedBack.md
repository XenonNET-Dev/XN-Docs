:::

## 安装

打开下载的压缩文件，将全部文件解压到游戏根目录即可  

可参考图片进行操作（此处以湾岸 6RR的作为演示）：  

![ffb_1](https://r2.kksk03.site/XenonNET/WebResources/ffb/ffb_1.avif)  

## 使用

1. 打开 `FFBPluginGUI.exe` ：  

![ffb_2](https://r2.kksk03.site/XenonNET/WebResources/ffb/ffb_2.avif)  

2. 点击第一项 `Force Feedback Setup` ，会出现以下界面：  

![ffb_3](https://r2.kksk03.site/XenonNET/WebResources/ffb/ffb_3.avif)  

3. 在左上角 `Device GUID` 中选择您的方向盘基座后即可：  

![ffb_4](https://r2.kksk03.site/XenonNET/WebResources/ffb/ffb_4.avif)  

## 注意

该插件不能完美还原街机的力反馈手感，会有比较明显的差异，因此请不要包有过高期望  
同时，部分方向盘基座无法使用该插件  

已知支持的设备：  

- 图马斯特 T150（只有部分力反馈效果）  
- 图马斯特 T300RS / GT（只有部分力反馈效果）  
- Moza R3 / R5 / R9（有全部力反馈效果）  
- 速魔 Alpha Mini（有全部力反馈效果）  

已知不支持的设备：  

- 莱仕达 V99
