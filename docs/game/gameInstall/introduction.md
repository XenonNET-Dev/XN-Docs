数据站主要提供以下功能：  

- 您的 `XenonNET` 账户的登入与注册

- 管理您的游戏数据，如车辆数据、用户物品等

- ...更多游戏相关功能，具体您可以自行探索  

::: tip
有一部分玩家会误认为 `XenonNET Hub` 中的账户仅仅只用于“开卡”。  
您访问 `XenonNET Hub` 时，应留意侧边栏所提供的选项，我们提供了很多功能，而并不仅仅只有“开卡”这一个功能。  
需要注意：注册成功 `XenonNET` 账户的同时，您的“卡”就已经开好了。  
:::

## 常见问题与解答

- **Q:** 游戏的存档是保存到我电脑本地吗？  
    **A:** 不是，与游戏厅中的实体机一样，游戏的存档是保存在服务器的。您只需要在游戏中的刷卡界面刷BanaPassport卡即可访问您的游戏数据。

- **Q:** BanaPassport卡是什么？  
    **A:** 这个问题想必在游戏厅中的实体机玩过的玩家都知道是什么。BanaPassport卡是游戏数据的访问通行证，在游戏里您刷您的卡即可访问您的游戏数据，同理，如果您刷他人的卡，也可以访问他人的数据。  

- **Q:** 我可以使用我以前的游戏本体来游玩吗？  
    **A:** 这得分具体情况。`XenonNET` 现已使用 `NXNavigator` 启动器来启动游戏，您可以在 `NXNavigator` 启动器上，在对应游戏中选择 `XenonNET` 服务器，选取原先的游戏本体后，启动游戏即可。但倘若您原本的游戏本体并不是使用该启动器来启动游戏的话，则还请您按照安装教程重新安装游戏。  

- **Q:** 我在安装游戏 / 日常玩游戏的过程中遇到意外情况怎么办？  
    **A:** 请访问 [问题解决](/game/gameInstall/faq) 以寻找您遇到的问题的对应的解决方案  

- **Q:** 我能使用方向盘基座这种外设进行游玩吗？  
    **A:** 可以。只要您能在游戏启动器绑定好对应按键，则无论任何外设都可以进行游玩。  

- **Q:** 我使用方向盘基座，我能获得与游戏厅中实体机一样的力反馈体验吗？  
    **A:** 这得分基座。目前实测如 `Moza` 这种直驱基座是可以获得近乎一样的体验，但也有部分基座无法获得一样的体验，具体您可以查阅 [力反馈补丁](/game/extras/forceFeedBack)  

## 游戏配置要求

如您的配置无法达到该要求，则可能会导致游戏无法以正常的帧速率运行。  

::: info 最低配置
- 处理器: Intel Core i5-3550S (3.00 GHz)
- 运行内存：8 GB DDR3 1600 MHz
- 显卡：NVIDIA GeForce GTX 650 Ti
- 硬盘空间：预留约25GB（单版本游戏）
- 硬盘：推荐使用固态硬盘
:::
