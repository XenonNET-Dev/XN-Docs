# XenonNET Docs

## 开发

首次开发需要安装 `Node.js` 至少 `22.0.0` 版本以上，建议使用 `24.15.0`  
随后由于使用了 `pnpm` ，所以还需要安装 `pnpm` ，右键Windows徽标，打开“终端（管理员）”并执行：  

```sh
npm install -g pnpm
```

然后就可以使用终端，在本源码目录内执行以启动开发服务器：  

```sh
pnpm install
pnpm dev
```

## 构建

```sh
pnpm build
```
